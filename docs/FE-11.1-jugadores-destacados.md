# FE-11.1 · NPCS-62

Ruta: `/organizador/destacados`, disponible en el menú del organizador.
`RutaProtegida` usa AuthContext y evita montar la pantalla o consultar datos si el rol no es ORGANIZADOR. Las acciones vuelven a autorizar la sesión en el servidor mediante `calendarioApi`.

## Contrato BE-11.1

- `GET /temporadas`: catálogo; se selecciona la temporada actual o la primera disponible.
- `GET /temporadas/{temporadaId}/jugadores-destacados?metrica=goles|asistencias`.
- Respuesta: `{ temporadaId, metrica, jugadores: [{ jugadorId, nombre, posicion, total }] }`.
- Se usa la ruta real del controller BE-11.1, con guion, aunque el enunciado de Jira la escribe sin guion.
- Se conservan el orden, los totales y las posiciones del servidor, incluidos los empates. No se recalculan estadísticas.
- Consultas sin caché; Actualizar vuelve a consultar para reflejar correcciones.

`SelectorTemporada`, `SelectorMetrica` y `TablaDestacados` viven en `components/destacados/vista-destacados.tsx`. El catálogo, los filtros y las respuestas son locales. Cada efecto invalida su respuesta al cambiar selección o desmontarse; una clave de selección evita presentar datos anteriores mientras llega la nueva consulta.

Estados separados: carga, datos, catálogo vacío, estadísticas vacías, error recuperable, sesión expirada (401 con enlace a login) y acceso denegado (403). Una temporada sin estadísticas muestra “No hay estadísticas oficiales para esta temporada”.
