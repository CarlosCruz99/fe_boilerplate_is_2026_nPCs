# FE-10.1 · NPCS-58

Ruta: `/mis-estadisticas`, accesible desde el menú de jugadores. La página usa RutaProtegida con rol JUGADOR: otras cuentas ven “No tienes permiso para ver esta página.” y no montan el contenido ni solicitan datos. AuthContext conserva sesión, rol y equipo; catálogo, selección y consultas viven en estado local.

## Contrato BE-10.1

- `GET /temporadas`: catálogo autenticado para el selector, con la temporada actual identificada.
- `GET /temporadas/{temporadaId}/mis-estadisticas`: `{ temporadaId, acumulados: { goles, asistencias, tarjetas }, partidos: [{ partidoId, fecha, rival, goles, asistencias, tarjetas }] }`.
- `equiposApi` verifica sesión y rol JUGADOR en servidor y envía Bearer con `cache: no-store`. No se envía jugadorId: BE-10.1 resuelve la ficha vinculada desde el token y exige inscripción confirmada en la temporada.
- Se valida el ID de temporada y se comprueba que la respuesta 200 tenga la temporada solicitada, acumulados y filas válidos. Las respuestas malformadas o de otra temporada se tratan como error 502, sin valores predeterminados.

## Componentes y estados

`SelectorTemporada`, `ResumenEstadisticas` y `DetallePorPartido` se definen en `components/estadisticas-personales/vista-estadisticas.tsx`.

La vista empieza sin selección y no pide estadísticas hasta elegir temporada. Muestra acumulados oficiales y fecha/hora en America/El_Salvador, rival, goles, asistencias y tarjetas, respetando el orden recibido. No recalcula totales ni ofrece edición.

Los estados inicial, cargando, éxito, vacío y error son distintos. Ceros se presentan únicamente tras 200 validado. Con `partidos: []` se muestra “Sin estadísticas durante esta temporada”. Un error no muestra resumen ni datos de otra selección; ofrece Reintentar. 401 incluye enlace de inicio de sesión; 403 conserva el mensaje de ficha/inscripción que devuelve el servicio.

El componente de datos se identifica por cuenta y temporada. Cambiar selección lo desmonta y `useConsulta` invalida las respuestas anteriores, evitando que sobrescriban la selección vigente. Reintentar vuelve a consultar el mismo catálogo o la temporada seleccionada, según el error.
